# Implementation Plan

## Overview
LP Generator - Nano Banana APIを使用したLP画像一括生成Webアプリケーション

---

## Tasks

- [x] 1. プロジェクトセットアップと基盤構築
- [x] 1.1 Next.jsプロジェクトの初期化とTypeScript設定
  - Next.js 14+ App Routerでプロジェクト作成
  - TypeScript strict mode有効化
  - Tailwind CSS、shadcn/uiのセットアップ
  - ESLint、Prettierの設定
  - _Requirements: 10.1_

- [x] 1.2 (P) 状態管理とフォームライブラリのセットアップ
  - Zustandストアの初期構造作成
  - React Hook FormとYupバリデーション設定
  - 基本的な型定義ファイル作成
  - _Requirements: 10.1_

- [x] 1.3 (P) UIコンポーネント基盤の構築
  - shadcn/uiから必要なコンポーネントをインストール（Button, Input, Card, Dialog等）
  - カラーテーマ設定（ライト/ダークモード対応）
  - レスポンシブレイアウトの基本構造作成
  - _Requirements: 10.1, 10.5_

- [x] 2. APIキー管理機能
- [x] 2.1 APIキーの保存・取得サービス実装
  - ローカルストレージへの暗号化保存機能
  - APIキーの取得とマスク表示機能
  - キーのクリア機能
  - _Requirements: 9.1, 9.2, 9.3_

- [x] 2.2 APIキー設定UIコンポーネント実装
  - APIキー入力フォーム
  - 保存済みキーの表示（マスク）
  - キーの有効性検証とフィードバック表示
  - 未設定時の警告表示
  - _Requirements: 9.1, 9.3, 9.4_

- [x] 3. ウィザードフレームワーク
- [x] 3.1 ウィザードコンテナとナビゲーション実装
  - ステップ状態管理（現在のステップ、完了状態）
  - 進む/戻るナビゲーション
  - ステップインジケーター表示
  - 各ステップの完了条件バリデーション
  - _Requirements: 10.2, 10.4_

- [x] 4. 画像アップロード機能
- [x] 4.1 画像アップロードサービス実装
  - ファイルからBase64への変換処理
  - 画像のリサイズ処理（API送信用最適化）
  - MIMEタイプ検証
  - _Requirements: 1.5_

- [x] 4.2 素材画像アップロードUI実装
  - ドラッグ&ドロップ対応のアップロードエリア
  - 画像プレビュー表示（サムネイル）
  - 最大6枚の制限と警告表示
  - 画像の削除機能
  - _Requirements: 1.1, 1.4, 10.3_

- [x] 4.3 (P) 参考デザイン画像アップロードUI実装
  - 素材画像とは視覚的に区別されたアップロードエリア
  - 画像プレビュー表示
  - 最大3枚の制限
  - 「これはイメージするLPの参考画像です」の説明表示
  - _Requirements: 1.2, 1.3, 1.4_

- [x] 4.4 画像使用方法の指定機能実装
  - 各素材画像に対する使用方法セレクター
  - 選択肢：メインビジュアル、背景、アイコン、商品画像、人物、自動配置
  - カスタム使用方法の自由入力
  - デフォルト値「自動配置」の適用
  - _Requirements: 3.1, 3.2, 3.3, 3.4_

- [x] 5. テキスト入力機能
- [x] 5.1 テキスト入力フォーム実装
  - メインキャッチコピー入力欄
  - サブキャッチコピー入力欄
  - 本文・説明文入力欄（テキストエリア）
  - CTAボタンテキスト入力欄
  - 各入力欄にプレースホルダー表示
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 10.4_

- [x] 5.2 (P) 追加テキストブロック機能実装
  - 動的にテキスト入力欄を追加する機能
  - 追加したブロックの削除機能
  - 入力内容の状態管理
  - _Requirements: 2.5_

- [x] 6. 色指定機能
- [x] 6.1 カラーピッカーコンポーネント実装
  - メインカラー選択UI
  - アクセントカラー選択UI
  - 背景色選択UI
  - HEXコード直接入力対応
  - 色のプレビュー表示
  - _Requirements: 4.1, 4.2, 4.3_

- [x] 6.2 (P) 参考画像からの色抽出機能実装
  - 参考デザイン画像がある場合に抽出オプション表示
  - 画像から主要色を抽出するアルゴリズム
  - 抽出した色の適用機能
  - _Requirements: 4.4, 4.5_

- [x] 7. 生成設定機能
- [x] 7.1 生成設定UI実装
  - アスペクト比表示（9:16固定、変更不可として表示）
  - 解像度選択（1K / 2K / 4K）、デフォルト2K
  - 生成枚数選択（1〜4枚）
  - 設定内容のサマリー表示
  - _Requirements: 5.1, 5.2, 5.3, 5.4_

- [x] 8. プロンプト生成機能
- [x] 8.1 プロンプトテンプレートと構築ロジック実装
  - LP生成用の英語プロンプトテンプレート作成
  - ユーザー入力（テキスト、色、画像使用方法）からの変数埋め込み
  - パディング最小化の指示を含める
  - 叙述的な文章構造の生成
  - _Requirements: 6.2, 6.3, 6.5, 6.6_

- [x] 8.2 日本語から英語への変換機能実装
  - Gemini APIのテキスト生成を使用した翻訳
  - キャッチコピーや説明文の自然な英語変換
  - 翻訳結果のキャッシュ
  - _Requirements: 6.1, 6.4_

- [x] 9. Gemini API連携機能
- [x] 9.1 APIクライアント実装
  - Nano Banana API（Gemini 3.0 Pro）への接続
  - LP画像を1枚ずつ生成するリクエスト構築
  - リクエスト構築（プロンプト、Base64画像、設定パラメータ）
  - レスポンス解析（Base64画像のデコード）
  - response_modalitiesの設定
  - _Requirements: 7.1, 7.2, 7.3, 7.4_

- [x] 9.2 エラーハンドリングとローディング状態管理
  - API呼び出し中のローディング表示
  - エラー発生時のメッセージ表示
  - リトライオプションの提供
  - レート制限（429）への対応
  - _Requirements: 7.5, 7.6_

- [x] 10. 生成結果表示・ダウンロード機能
- [x] 10.1 生成結果プレビュー実装
  - 生成された画像のプレビュー表示
  - 複数画像のギャラリー表示
  - 画像の拡大表示機能
  - _Requirements: 8.1_

- [x] 10.2 (P) ダウンロード機能実装
  - 単一画像のPNGダウンロード
  - ファイル名の自動生成（日時ベース）
  - _Requirements: 8.2, 8.3_

- [x] 10.3 (P) 一括ダウンロード機能実装
  - JSZipを使用したZIPファイル生成
  - 複数画像の一括ダウンロード
  - _Requirements: 8.4_

- [x] 10.4 生成履歴機能実装
  - セッション内での生成履歴保持
  - 履歴からの再ダウンロード
  - 履歴のクリア機能
  - _Requirements: 8.5_

- [x] 11. 統合とエンドツーエンドフロー
- [x] 11.1 全ステップの統合
  - ウィザードの全ステップを連結
  - 各ステップ間のデータ引き継ぎ確認
  - 入力内容の確認画面実装
  - 生成実行から結果表示までのフロー完成
  - _Requirements: 10.2_

- [x] 11.2 入力バリデーションとエラー表示
  - 必須項目のバリデーション
  - APIキー未設定時の生成ボタン無効化
  - 画像枚数超過時のエラー表示
  - フィールドレベルのエラーメッセージ
  - _Requirements: 1.3, 9.4_

- [ ] 12. テスト実装
- [ ] 12.1 ユニットテスト実装
  - プロンプト生成ロジックのテスト
  - APIキー暗号化/復号化のテスト
  - 画像Base64変換のテスト
  - 色抽出アルゴリズムのテスト
  - _Requirements: 全体_

- [ ] 12.2 (P) 統合テスト実装
  - API呼び出しのモックテスト
  - ウィザードフローの画面遷移テスト
  - 状態管理の永続化テスト
  - _Requirements: 全体_

- [ ] 12.3 (P) E2Eテスト実装
  - 完全なLP生成フローのテスト
  - エラーハンドリングフローのテスト
  - レスポンシブデザインの確認
  - _Requirements: 10.1_
